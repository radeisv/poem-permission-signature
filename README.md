The Second Signature — a short poem about agency: the power to ask and to be given. A program that writes one poem to `/output/entry.txt`: after sixty years of having her name signed by someone else, she asks to sign it herself — and the second time, it looks like hers.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt`. No network, no randomness, no model call — every run writes the same bytes.
